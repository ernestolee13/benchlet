# 5단계 산출 (2026-10-03, 공개 벤치 축약 시드)

사용자 지시: 모델별 답안이 공신력 있게 공개된 유명 벤치를 찾아, 우리 규모(수십~수백)로 줄이되 여러 모델의 정답률이 보존되게 줄여 플랫폼의 초기 시드로 넣는다. 조사는 `docs/RESEARCH_public_seeds.md`.

## 원천과 접근

- 모델별 항목 정오: **metabench 논문 데이터**(Kipnis et al. 2025, Zenodo 12819251, CC-BY-4.0). Open LLM Leaderboard v1 의 모델 5,000개 이상이 ARC·HellaSwag·MMLU·TruthfulQA·WinoGrande·GSM8K 항목마다 맞혔는지가 long CSV 로 있다. 프롬프트 파일(few-shot 전체)의 마지막 블록을 HF 원천 항목에 맞춰 정렬했다(`src/prepare_matrices.py`). 정렬률: ARC 1172/1172, TruthfulQA 817/817, WinoGrande 1267/1267, HellaSwag 10042/10042, MMLU 13217/14042.
- 항목 본문: HF datasets-server(인증 없음)로 덤프. 리포에는 넣지 않는다(축약본만).
- 못 쓴 것: Open LLM Leaderboard v2 details(게이트, 토큰 없음), GPQA(공개 재게시 자제 요청), KMMLU·HAE-RAE(ND 라이선스). HELM 공개 버킷은 접근되나 이번엔 쓰지 않았다.

## 축약 규칙 (`benchlet distill`)

모델을 적합 70% / 검증 30% 로 나누고(시드 고정), 검증 모델에서만 「부분집합 정확도 대 전체 정확도」의 MAE·최대 오차·Kendall τ 를 보고한다. 세 방법을 구현해 실데이터에서 비교했다.

| 방법 | 선택 | 추정 | 비고 |
|---|---|---|---|
| stratified (기본) | 모델 정답률 5분위 층화 비례 + 적합 모델 기준 교환 탐색(목적: 오차 평균·최대 + 1 − Spearman) | 부분집합 정확도 그대로 | 가중치·추정기 없이도 쓸 수 있다. 사용자가 그냥 돌리면 된다 |
| irt | 1PL(Rasch) 적합 뒤 난이도 분위 중앙 항목 | p-IRT(본 항목 관측 + 못 본 항목 예측) | tinyBenchmarks 꼴. 난이도 b 를 메타데이터로 남긴다 |
| anchor | 정오 벡터 k-means(k=n) 메도이드 | 군집 크기 가중 평균 | Anchor Points 꼴. 가중치 없이는 못 쓴다 |

실데이터(모델 800, 검증 240) 100건 축약 결과. 기준선은 층화 무작위.

| 벤치 | 전체 항목 | stratified MAE / 최대 / τ | irt (p-IRT) | anchor (가중) | 층화 무작위 |
|---|---|---|---|---|---|
| ARC-Challenge | 1,170 | 1.69 / 6.69 / 0.887 | 2.17 / 8.64 / 0.880 | 2.11 / 13.37 / 0.858 | 2.15 / 8.59 / 0.891 |
| TruthfulQA MC1 | 817 | 1.51 / 5.42 / 0.922 | 1.95 / 7.62 / 0.887 | 1.96 / 20.00 / 0.888 | 2.74 / 12.87 / 0.853 |
| WinoGrande | 1,267 | 2.01 / 8.49 / 0.848 | 2.53 / 10.19 / 0.823 | - | 2.47 / 7.96 / 0.758 |
| HellaSwag | 9,902 | 1.32 / 6.45 / 0.894 | 1.84 / 10.01 / 0.787 | - | 2.08 / 7.45 / 0.892 |

읽는 법. 100건이면 검증 모델 정확도를 1.3~2.0pp 안에서 재현하고 순위 상관 0.85~0.92 다. tinyBenchmarks 가 보고한 「100건, 약 2%」와 같은 수준이다. 방법 간 차이는 0.5~1pp 라 n 이 더 중요하다. 합성(Rasch) 데이터에서는 세 방법이 구분되지 않았고 실데이터에서만 stratified 가 앞섰다(항목 간 상관 구조 덕).

## 시드 벤치 (전부 n=100, 선택지는 항목별 결정론적 셔플, 원천 정답 위치는 metadata)

| 벤치 | 라이선스 | 축약에 쓴 모델 수 | 검증 MAE | 검증 τ | glm | qwen | deepseek | jev |
|---|---|---|---|---|---|---|---|---|
| arc-challenge-mini | CC-BY-SA-4.0 | 800 | 1.69pp | 0.887 | 90 | 95 | 92.9 | 97 |
| truthfulqa-mc1-mini | Apache-2.0 | 800 | 1.51pp | 0.922 | 67 | 85 | 76 | 93 |
| winogrande-mini | CC-BY | 800 | 2.01pp | 0.848 | 54 | 73 | 60 | 47 |
| hellaswag-mini | MIT | 800 | 1.32pp | 0.894 | 83 | 91 | 79.6 | 95 |
| mmlu-mini | MIT | 500 | 1.97pp | 0.834 | 74 | 75 | 76 | 93 |

OpenRouter 4팔 작성자 실행(2026-10-03), 정확도 %. 다섯 모두 GitHub 리포에 게시했고 갤러리는 23개가 됐다. 읽는 법.
- 축약본에서도 팔 간 순위가 벤치마다 다르다. TruthfulQA·HellaSwag·ARC·MMLU 는 jev 가 앞서고 WinoGrande 는 qwen 이 앞선다. WinoGrande 에서 jev 47% 는 2지 우연 수준이다. typed 팔의 choice 가 「이름 둘 중 고르기」에서 약한지, 질문 문구 탓인지는 질문 스모크로 가를 일이다(다음 판).
- deepseek 의 결측(98/100, 93/100)은 첫 토큰이 라벨이 아닌 항목(라벨 질량 미달)이다.
- 검증 MAE 는 metabench 모델(2023~2024 오픈 모델) 기준이다. 우리 4팔은 그 집단 밖이라 「축약본 정확도 = 전체 정확도」를 보장하지 않는다. 100건의 Wilson 구간(±10pp)이 그대로 적용된다.

## 아직 아닌 것

- GSM8K(단답 생성)는 우리 러너가 선택형만 다뤄 뺐다. 생성 팔 채점기(숫자 정규화)가 생기면 넣는다
- 한국어 공개 벤치는 모델별 항목 답안이 공개된 것이 없어 축약 검증을 못 한다. KoBEST(CC-BY-SA)는 층화 무작위로만 가능
- 검증 모델 집단이 Open LLM Leaderboard v1(2023~2024 오픈 모델)이라 최신 상용 모델에서의 보존은 재지 않았다
