# 결함 사례집 (우리가 236항목 만들며 잡은 것)

1. **자기 검증은 순환.** 빌더가 「불일치 0건」을 세 번 출력했는데 파서를 파서로 확인한 것이었다
2. **복합 금액 조각남.** 「6조315억원」→315억. 라벨 3개가 뒤집힐 뻔했다. 파서를 사람이 표본 검사한다
3. **「정확히 하나만 만족」이 거짓.** 라우트 A 와 D 가 동시에 성립. 우선순위 한 줄이 필요했다
4. **글자 충돌.** 선택지 본문에 「C. 백링크」가 들어가 「A. C. 백링크」가 됐다
5. **음성이 자명.** 「100억을 넘는가」의 음성이 전부 값 없는 문장. 유무만 보면 만점. qwen 100%→27%
6. **심은 결함이 새는 네 가지.** 비문(「너무 6개 항목이」), 태 뒤집힘(「확인됐다」→「확인한 것으로 보인다」), 주체 오류(「악질 기업 환경부가」), 내용 모순(긍정 사례에 비난 어휘)
7. **선택지 교체가 무효.** 「있다/없다」 구조라 바꿔도 성립. V1 8건 중 6건 오라벨. 질문은 두고 유형만 어긋나게
8. **극성 불일치.** 질문 「맞는가」인데 label 0 = 「어긋남」. Jev 가 4.2%→85.4%
9. **soft 규칙 이진화.** 반말 종결은 soft 인데 위반으로 물어 네 팔 전부 0%
10. **CLEAN 오라벨.** 승인된 요약에 lint 가 못 잡는 논평(「오히려」「뒤늦은」)이 있었다
11. **작성자 문장 편향.** 내가 쓴 준수본은 「깨끗하게」 읽힌다. 준수본도 원자료에서
12. **파서 검증 라벨도 사람이 본다.** 기관 목록에 법원 누락 등, 기계 라벨이 틀렸다
